# Arai

Arai is a platform for building, deploying, and managing autonomous agents. It provides a runtime for agent execution, standard protocol support, and the infrastructure needed to operate agents responsibly at scale.

The project emphasises interoperability with open standards, capability isolation through WebAssembly, and clear boundaries for what agents can and cannot do.

Arai is part of the [Rai](https://github.com/rai-vision) ecosystem.
